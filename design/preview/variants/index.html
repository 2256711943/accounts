一拍记 · 视觉方向对比稿（A / B / C）

三套稿子的版式、间距、信息结构完全一样，差异只在 token（颜色 / 圆角 / 阴影 / 字阶）——所以哪套好看是纯粹的视觉偏好判断。
挑一套，或者说「要 A 的底色 + C 的圆角」，我再收敛成最终版并写回 tokens.json。此外这三套都是「配色方向」层面的对比，页面结构若也要改，是下一步的事。

方案 A · 冷调专业感（靛蓝 + 冷灰白）
冷灰白底 + 靛蓝主色，卡片纯白浮起，双层柔和投影 + 中等圆角。气质克制可信，最像成熟金融产品；风险是「标准答案」，个性偏弱。三套里最保险的一套。
方案 B · 深色高级感（近黑 + 亮橙）
近黑底 + 亮橙主色，卡片靠明度差浮起，圆角最大、投影最深。深色天然有纵深感，「素/平」的问题解决得最彻底，也最显贵。代价：白天户外可读性最差，屏幕亮度敏感的机型上偏暗；后续每个页面都要按深色重新校一遍对比度。
方案 C · 亮白现代感（紫罗兰 + 大圆角）
近白底 + 紫罗兰主色，圆角最大、投影最重且带色，字阶落差最大。最年轻、最「产品感」，一眼看上去最不像学生作业。代价：紫蓝系正是 UI_SPEC §1.2 专门避开的 AI 生成设计重灾区，撞脸风险最高。
